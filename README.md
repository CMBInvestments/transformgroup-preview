# Transform Group website redesign (preview)

Clickable design concept for The Transform Group (transformgroupnj.com).

- `index.html` is a single self-contained page: Home, Sell, Invest, About, Contact and a phone-size view, switched from the bar at the top.
- Items in [brackets] are placeholders for real content. Forms are not live.
- Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > main branch, root) to get a shareable link.
